# Drafts

Anything in this folder is **not published**. Jekyll ignores `_drafts/` unless
you explicitly ask for it (`jekyll serve --drafts` locally).

Use it for notes in progress, and for `TEMPLATE-copy-me.md`, which is the
front matter for a new post.

To publish a draft, move it to `_posts/` and rename it with a date prefix:

    _drafts/my-note.md  ->  _posts/2026-10-25-my-note.md

The filename date is what orders the Writing page, so it must match the
`date:` in the front matter.
